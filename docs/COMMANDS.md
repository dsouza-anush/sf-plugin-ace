# Command reference

Generated by `npm run docs` from the operation catalog and message bundles. Run `sf ace schema --json` for structural body schemas and `sf ace COMMAND --help` for full flag help. Every command supports Salesforce JSON output.

## sf ace setup

Provision and verify headless ACE authentication with a JWT external client app.

Requires an existing administrator `--target-org`, an active `--username`, and an existing ACTIVE `--agent-id` for verification. `--dry-run` returns a local plan; execute with `--allow-write` and confirmation. CI uses `--no-prompt --confirm FINGERPRINT`. Supports `--app-name`, `--alias`, `--contact-email`, and permanent `--key-dir`. See [headless setup](../README.md#headless-setup).

## sf ace schema

Describe ACE commands, parameters, and JSON request schemas without authentication.

Offline helper; makes no network request. `--command "ace session create"` narrows the output to one operation.

## sf ace session list

List sessions in an authorized conversation.

`GET /api/v1/agentic/conversations/{conversationId}/sessions`

| Flag | Wire location/name | Required |
| --- | --- | --- |
| `--agent-id` | header: `agent_id` | Yes |
| `--conversation-id` | path: `conversationId` | Yes |
| `--owner-id` | query: `owner_id` | Yes |
| `--owner-type` | query: `owner_type` | Yes |
| `--status` | query: `status` | No |
| `--time-range` | query: `time_range` | No |
| `--fields` | query: `fields` | No |
| `--participant-id` | query: `participant_id` | No |
| `--page-token` | query: `page_token` | No |
| `--source` | local: `index` or `conversation` | No |

`--source index` (default) uses the native session index. `--source conversation` projects session summaries from the conversation graph, including closed sessions the index omits. It supports status and id/startTime/status fields, rejects participant/time-range filters, and preserves graph pagination.
